# Tài liệu Vexo

Thư mục này là điểm vào tiếng Việt cho tài liệu Vexo. Tài liệu tiếng Anh (`en`) là nguồn chuẩn; cây thư mục này giữ cùng cấu trúc để dễ tra cứu.

3. [Định dạng giao dịch](./specs/tx-format.md)
4. [Vòng đời validator](./specs/validator-lifecycle.md)
