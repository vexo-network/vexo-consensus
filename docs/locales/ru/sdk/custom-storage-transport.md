# Руководство по пользовательскому хранилищу и транспорту

> Locale: ru · Русский
> Этот документ — русский сопроводительный документ к английскому источнику. Протокол, безопасность и решения о release остаются нормативными на английском языке.


## С чего начать

Этот документ объясняет, как реализовать и зарегистрировать custom storage и transport adapter. Если вы делаете это впервые, читайте в таком порядке.

1. Custom Storage
2. Storage Requirements
3. Custom Transport
4. Transport Requirements
5. Compatibility

Такой порядок соответствует рискам, которые нужно проверить в первую очередь: сначала убедиться, что хранилище выдерживает crash, pruning, snapshot и replay, а затем проверить, что transport правильно обрабатывает аутентификацию, согласование версий, reconnect и ban.
